## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `heading` | `string` | — | Slide title |
| `summary` | `string` | — | Subtitle below the heading |
| `header` | `string` | — | Pillar/section header at top |
| `footer` | `boolean` | `false` | Show footer bar |
| `pageNumber` | `boolean` | `false` | Show page number |

## Item Fields

Each item in the list accepts:

| Field | Type | Required | Description |
|---|---|---|---|
| `value` | `string` | yes | The big number (e.g., `"$4.2M"`, `"99.98%"`) |
| `label` | `string` | yes | Description below the number |
| `icon` | `string` | no | Lucide icon name |
| `trend` | `string` | no | Trend text (e.g., `"+38% YoY"`) |

## Tips

- 3-4 items is the sweet spot; 2 looks sparse, 5+ gets crowded
- Format values for impact: `"$4.2M"` not `"$4,200,000"`
- Use `trend` to add context -- growth rates, comparisons, benchmarks
- Icons are optional but add visual weight
- Works great for investor decks, quarterly reviews, and campaign results
