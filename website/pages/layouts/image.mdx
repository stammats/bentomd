## Example

```yaml
---
theme: default
title: Product Screenshot
aspectRatio: "16:9"
palette:
  primary: "#2563eb"
---

---
layout: image
heading: "Dashboard Overview"
summary: "Real-time monitoring across all services"
src: "https://images.unsplash.com/photo-1551288049-bebda4e38f71?w=1600&h=900&fit=crop"
fit: contain
caption: "The unified dashboard provides a single pane of glass for all operational metrics"
footer: true
pageNumber: true
---
```

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `heading` | `string` | — | Slide title |
| `summary` | `string` | — | Subtitle below the heading |
| `src` | `string` | — | Image URL or relative path |
| `fit` | `"cover" \| "contain" \| "auto"` | `"contain"` | How the image fits its container |
| `position` | `string` | `"center"` | CSS object-position for the image |
| `caption` | `string` | — | Caption text below the image |
| `footer` | `boolean` | `false` | Show footer bar |
| `pageNumber` | `boolean` | `false` | Show page number |

## Tips

- `fit: contain` shows the full image with letterboxing
- `fit: cover` fills the container and crops edges
- Use relative paths for local images: `src: "./assets/screenshot.png"`
- Add a `caption` to provide context for the image
- Works great for product screenshots, architecture diagrams, and photo showcases
- The image automatically sizes to fill the available content area
