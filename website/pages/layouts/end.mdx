# end

## Example

```yaml
---
layout: end
background: "#0f172a"
---

# Thank You

## Questions? Let's talk.

Sarah Chen | sarah@company.com | @sarahchen

Company, Inc. | company.com
```

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `background` | `string` | palette background | Background color or gradient |
| `align` | `string` | `"center"` | Text alignment |
| `color` | `string` | auto | Text color |

## Tips

- Use the same `background` as your `cover` slide for visual consistency
- `#` heading is the sign-off, `##` is a call to action
- Body text below the headings is used for contact info
- No headers, footers, or page numbers are shown
- Keep it simple -- one CTA at most
