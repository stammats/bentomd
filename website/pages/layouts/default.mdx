## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `heading` | `string` | — | Slide title (H1) |
| `summary` | `string` | — | Subtitle below the heading |
| `header` | `string` | — | Pillar/section header at top |
| `footer` | `boolean` | `false` | Show footer bar |
| `pageNumber` | `boolean` | `false` | Show page number |
| `valign` | `"top" \| "center" \| "bottom"` | `"top"` | Vertical alignment of body content |

## Tips

- Body content is standard Markdown: paragraphs, bullet lists, code blocks, bold/italic
- Keep to 7 bullet points max at default font size (10 at minimum size)
- Code blocks are syntax highlighted automatically
- The heading auto-scales from 56px down to 40px if it's long
- Great for agendas, narrative slides, and code showcases
