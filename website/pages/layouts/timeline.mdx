## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `heading` | `string` | -- | Slide title |
| `summary` | `string` | -- | Subtitle below the heading |
| `header` | `string` | -- | Pillar/section header at top |
| `footer` | `boolean` | `false` | Show footer bar |
| `pageNumber` | `boolean` | `false` | Show page number |

## Item Fields

Each item in the list accepts:

| Field | Type | Required | Description |
|---|---|---|---|
| `date` | `string` | no | Date label (e.g., `"Jan 2026"`) |
| `title` | `string` | yes | Milestone name |
| `description` | `string` | no | One-line description |
| `active` | `boolean` | no | Highlight as current phase |

## Tips

- 3-5 items is ideal; more than 6 gets hard to read
- Use `{active}` on the current milestone to orient the audience
- Keep descriptions to one sentence
- Dates can be any format: `"Q3 2026"`, `"March"`, `"Week 4"`
