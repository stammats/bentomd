# two-column

Two content areas side by side. Use `##` headings to separate left and right columns.

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `heading` | `string` | — | Slide title |
| `summary` | `string` | — | Subtitle below the heading |
| `header` | `string` | — | Pillar/section header at top |
| `ratio` | `string` | `"1:1"` | Column width ratio (e.g., `"2:1"`, `"1:2"`) |
| `footer` | `boolean` | `false` | Show footer bar |
| `pageNumber` | `boolean` | `false` | Show page number |
| `gap` | `"sm" \| "md" \| "lg"` | `"md"` | Gap between columns |

## Tips

- Use `##` headings to split content into left and right columns
- The first `##` becomes the left column, the second becomes the right
- Each column supports full Markdown: bullets, tables, code blocks, images
- Use `ratio: "2:1"` for a main content + sidebar layout
- Keep to 5 bullet points per column max
- Works well for before/after, pros/cons, and comparison slides
