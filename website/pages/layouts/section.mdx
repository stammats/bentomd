# section

Section break / interstitial with large centered text. Use to separate major sections of a presentation.

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `background` | `string` | palette background | Background color |
| `color` | `string` | auto | Text color |
| `align` | `string` | `"center"` | Text alignment |

## Tips

- Use `#` for the section title and `##` for a tagline
- Dark backgrounds create strong visual breaks between sections
- No header, footer, or page number -- keep it minimal
- Keep the title short: 3-5 words is ideal
- Great for creating rhythm in long presentations (20+ slides)
- Use between major topic changes to help the audience reset
