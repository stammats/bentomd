# bento

Flexible grid layout with cells of varying sizes. Each cell supports icon, title, description, image, value, and label. Cells are auto-placed using bin-packing, and row gaps are automatically filled.

## Size Keywords

| Keyword | Columns | Rows | Description |
|---|---|---|---|
| `sm` | 4 (1/3) | 1 | Small card |
| `md` | 6 (1/2) | 1 | Medium card |
| `lg` | 8 (2/3) | 1 | Large card |
| `wide` | 12 (full) | 1 | Full-width banner |
| `tall` | 4 (1/3) | 2 | Tall sidebar card |
| `hero` | 8 (2/3) | 2 | Hero feature block |
| `full` | 12 (full) | 2 | Full-width hero |

You can also use explicit notation: `size: "6x2"` means 6 columns wide, 2 rows tall.

## Item Syntax

Each `###` heading defines one cell:

```markdown
### :icon-name: Title text {size modifier}
Description text below the heading.
![](image-url)
```

- `:icon-name:` -- Lucide icon (optional, at start of heading)
- `{size}` -- Size keyword (optional, at end of heading)
- `{center}` -- Center-align content
- Value cells: start the title with a number or currency symbol (e.g. `### $4.2M`)
- Image cells: add `![](url)` in the body

## Color Schemes

Use `scheme` in the slide frontmatter for automatic cell coloring:

| Scheme | Style |
|---|---|
| `pastel` | Soft pastels (purple, pink, yellow, green, blue, orange) |
| `ocean` | Cool blues and teals |
| `warm` | Warm yellows, oranges, and pinks |
| `mono` | Neutral grays |

Image behavior:
- **Background image**: `![](url)` without icon/value -- image fills the entire cell
- **Inline image**: `![](url)` with `:icon:` or title -- image appears below the text content

## Tips

- Cells are auto-placed using a greedy bin-packing algorithm -- no positions needed
- Row gaps are automatically filled by expanding the last cell in each row
- Use `scheme: pastel` in the slide frontmatter for automatic pastel cell colors
- Mix `hero`/`tall`/`lg` with `sm` cells for visual hierarchy
- Image cells: add `![](url)` in the body -- title/description overlay at bottom
- Value cells: start the heading with a number or `$` (e.g. `### $4.2M {sm center}`)
- `{tall}` creates a 2-row vertical span -- great for sidebars and featured content
