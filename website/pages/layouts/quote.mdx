## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `heading` | `string` | — | Slide title |
| `header` | `string` | — | Pillar/section header at top |
| `footer` | `boolean` | `false` | Show footer bar |
| `pageNumber` | `boolean` | `false` | Show page number |

## Tips

- Use Markdown blockquote syntax (`>`) for the quote text
- Place the attribution on a new line after the quote with `—` (em dash)
- Use `**bold**` for the person's name in the attribution
- Keep quotes to 2-4 sentences for maximum impact
- One quote per slide -- let it breathe
- Works well for customer testimonials, expert opinions, and key takeaways
