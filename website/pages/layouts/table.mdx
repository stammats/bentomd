## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `heading` | `string` | — | Slide title |
| `summary` | `string` | — | Subtitle below the heading |
| `header` | `string` | — | Pillar/section header at top |
| `footer` | `boolean` | `false` | Show footer bar |
| `pageNumber` | `boolean` | `false` | Show page number |

## Tips

- Use standard Markdown table syntax in the body content
- The first row is automatically styled as the header
- Keep to 5-7 rows for readability; more rows trigger font auto-scaling
- 4-6 columns is optimal for the 16:9 canvas
- Use short cell values -- `"Yes"` / `"No"` / `"Partial"` rather than long sentences
- Great for vendor comparisons, feature matrices, and data summaries
