```markdown
---
layout: image-left
heading: "Real-time Collaboration"
summary: "Work together seamlessly"
```

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `heading` | `string` | -- | Slide title (spans full width) |
| `summary` | `string` | -- | Subtitle below the heading |
| `src` | `string` | -- | Image URL |
| `fit` | `string` | `"cover"` | `cover`, `contain`, or `auto` |
| `footer` | `boolean` | `false` | Show footer bar |
| `pageNumber` | `boolean` | `false` | Show page number |

## Tips

- The image fills the left half; text content fills the right half
- Text is vertically centered in the right column
- Use `## headings` in the body for multi-section text
- Works well for product screenshots + feature descriptions
- Pair with `image-right` for visual variety across slides
