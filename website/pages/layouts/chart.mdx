## Example

```yaml
---
theme: default
title: Revenue Growth
aspectRatio: "16:9"
palette:
  primary: "#2563eb"
---

---
layout: chart
heading: "Monthly Recurring Revenue"
summary: "Consistent growth trajectory over the past 6 months"
type: bar
showValues: true
showLegend: false
footer: true
pageNumber: true
---

### Jul: 280

### Aug: 310

### Sep: 345

### Oct: 390

### Nov: 420

### Dec: 485
```

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `heading` | `string` | — | Slide title |
| `summary` | `string` | — | Subtitle below the heading |
| `header` | `string` | — | Pillar/section header at top |
| `type` | `string` | `"bar"` | Chart type (currently `bar`) |
| `showValues` | `boolean` | `false` | Display values on the chart |
| `showLegend` | `boolean` | `true` | Show chart legend |
| `colors` | `string[]` | palette colors | Custom colors for data points |
| `footer` | `boolean` | `false` | Show footer bar |
| `pageNumber` | `boolean` | `false` | Show page number |

## Item Fields

Each data point accepts:

| Field | Type | Required | Description |
|---|---|---|---|
| `label` | `string` | yes | Category label (x-axis) |
| `value` | `number` | yes | Numeric value (y-axis) |
| `color` | `string` | no | Override color for this data point |

## Tips

- 4-8 data points works best; fewer looks empty, more gets crowded
- Use short labels (abbreviations, month names) to avoid overlap
- Enable `showValues: true` when exact numbers matter
- The chart automatically scales to the data range
- Use consistent units across data points
