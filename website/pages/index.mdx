# bentomd

**Modular slide decks from Markdown + YAML. Built for the AI era.**

Pixel-perfect slides that always fit 16:9 or 4:3. 10 built-in layouts. AI-native syntax.

## Features

- 📐 **Pixel-Perfect** — Fixed canvas rendering (1920×1080) with transform scaling
- 🧱 **Modular Layouts** — cover, stats, charts, tables, features, and more
- 🤖 **AI-Native** — Simple YAML + Markdown syntax designed for LLM generation
- 🎨 **Beautiful Defaults** — Professional typography, spacing, and color system
