# bentomd

**Modular slide decks from Markdown. Write cells, not layouts.**

bentomd turns plain Markdown into pixel-perfect 16:9 slide decks. Use `---` to separate slides and `###` to define cells. Content type is detected automatically — text, lists, images, charts, and more.

## How It Works

Three rules cover everything:

1. **`---`** separates slides
2. **`##`** is the slide title
3. **`###`** is a bento cell — content inside determines how it renders

```markdown
---
theme: ocean
title: My Deck
---

## Why bentomd

### :zap: Zero Config
Write Markdown. Get slides.

### **42%** Faster {sm center}
Than the previous approach

### :shield: Open Source {md}
MIT licensed. No lock-in.
```

## Key Concepts

- **Auto-bento layout** — cells are placed with bin-packing, no positions needed
- **Auto-detected content** — text, lists, images, tables, blockquotes, mermaid diagrams
- **`{size}` hints** — `{hero}`, `{tall}`, `{md}`, `{sm}`, `{wide}` control cell dimensions
- **`**bold**` in titles** renders large, for metrics like `### **42**% Growth`
- **6 themes** — default, ocean, sunset, forest, berry, mono
- **6 cell styles** — mixed, tint, solid, outline, white, mono

## Get Started

```bash
npm install bentomd
npx bentomd dev deck.bmd
```
