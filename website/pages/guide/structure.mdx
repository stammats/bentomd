# Slide Structure

A bentomd file is plain Markdown. Three constructs cover the entire syntax.

## File Layout

```
[global frontmatter]
---
[slide 1 content]
---
[slide 2 content]
---
[slide 3 content]
```

The first block before any `---` is the **global frontmatter** (YAML). Everything after is slides separated by `---`.

## Global Frontmatter

The first block configures the whole deck:

```markdown
---
theme: ocean
title: Q4 Review
style: tint
borderRadius: 24
---
```

See [Global Config](/guide/config) for all options.

## Slides

Each slide is a block of Markdown. The `---` separator begins a new slide.

```markdown
---
theme: default
title: Platform Overview
---

## Platform Overview

### :shield: Security {md}
SOC 2 Type II, GDPR, HIPAA compliant.

### **99.99%** {sm center}
Uptime SLA

---

## Pricing

### Starter — Free
Up to 3 projects

### Pro — $49/mo {md highlight}
Unlimited projects, priority support

### Enterprise
Custom pricing and SLAs
```

## `##` — Slide Title

The `##` heading sets the slide title. Text between `##` and the first `###` becomes subtitle text.

```markdown
## Market Analysis

This slide summarizes our Q3 findings.

### North America {md}
Strong growth in enterprise segment.

### EMEA {md}
Expansion opportunity in mid-market.
```

The subtitle text ("This slide summarizes...") appears below the heading before the bento grid.

## `###` — Bento Cells

Each `###` heading defines one bento cell. Content inside determines how it renders:

| Content | Renders As |
|---|---|
| Plain text in the body | Text card |
| Bullet list (`- item`) | List card |
| `> blockquote` | Quote card |
| `![](url)` as the only body content | Full-bleed image card |
| `![](url)` with text above it | Card with inline image |
| ` ```mermaid ``` ` block | Diagram card |
| Markdown table | Table card |
| `**bold**` in the title | Large metric value |

### Size Hints

Add `{size}` at the end of the `###` line to control the cell's grid span:

| Hint | Columns | Rows | Description |
|---|---|---|---|
| `{sm}` | 4 of 12 | 1 | Small card (default when unspecified with peers) |
| `{md}` | 6 of 12 | 1 | Medium card — half width |
| `{lg}` | 8 of 12 | 1 | Large card — two-thirds width |
| `{wide}` | 12 of 12 | 1 | Full-width banner |
| `{tall}` | 4 of 12 | 2 | Tall sidebar card — double height |
| `{hero}` | 8 of 12 | 2 | Hero block — two-thirds wide, double height |

```markdown
### :camera: Hero Feature {hero}
The main selling point gets the biggest card.

### **2.4K** {sm center}
Active users

### :star: Highly Rated {sm}
4.9 / 5 from 800+ reviews
```

### `{center}` Modifier

Add `{center}` (alone or combined with a size) to center the cell content. Useful for metric cards.

```markdown
### **$4.2M** {md center}
Annual Recurring Revenue

### **340%** {sm center}
YoY Growth
```

### `**bold**` for Large Values

Bold text in a `###` title renders at large display size — perfect for KPI cards:

```markdown
### **42**% Growth {sm center}
Year over year

### **$1.2M** Revenue {sm center}
Last quarter
```

## Full-Screen Layouts

Three layouts bypass the bento grid and render full-screen:

- **`cover`** — opening title slide. Use `# Title`, `## Subtitle`, and a plain line for attribution.
- **`section`** — divider slide between major sections.
- **`end`** — closing slide.

These require explicit frontmatter with `layout:`:

```markdown
---
layout: cover
background: "#1e293b"
---

# Product Strategy 2026
## Accelerating Growth Through Innovation

Sarah Chen · VP Product · March 2026
```

All other slides — anything with `###` cells — use the auto-bento grid automatically.

## `background:` on Any Slide

Any slide can have a background color:

```markdown
---
background: "#0f172a"
---

## Dark Slide

### :moon: Night Mode {md}
Supports dark backgrounds automatically.
```

The text color adapts automatically based on contrast.
