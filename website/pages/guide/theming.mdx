# Theming

bentomd has two independent visual controls: **theme** (palette presets) and **style** (how cells are painted). Both are set in the global frontmatter and apply to the entire deck.

## Themes

`theme:` sets the base color palette. Seven built-in themes are available:

| Theme | Description |
|---|---|
| `default` | Blue and purple on white |
| `ocean` | Teal and blue on white |
| `sunset` | Coral and amber on white |
| `forest` | Green and teal on white |
| `berry` | Purple and pink on white |
| `mono` | Charcoal gray on white |
| `custom` | Your own colors via `palette.primary` (and optional `secondary`) |

```markdown
---
theme: ocean
title: My Deck
---
```

## Cell Styles

`style:` controls how bento cells are painted. Six options are available:

| Style | Description |
|---|---|
| `mixed` | Alternating light/dark cells from the palette (default) |
| `tint` | Light pastel tints of each accent color |
| `solid` | Full-color backgrounds with white text |
| `outline` | Transparent cells with colored borders and text |
| `white` | White background, colored text and icons |
| `mono` | Single-hue variations using only the primary color |

```markdown
---
theme: default
style: tint
---
```

## Custom Theme

Use `theme: custom` with `palette.primary` to build a deck around your brand color. A complementary `secondary` is auto-generated, or you can set it explicitly.

```markdown
---
theme: custom
palette:
  primary: "#4CC9FF"
---
```

### Color Tokens

| Token | Used For |
|---|---|
| `primary` | Cell accents, icons, highlights, chart colors |
| `secondary` | Secondary accents (auto-generated if omitted) |
| `background` | Slide background |
| `surface` | Card backgrounds, code blocks |
| `text` | Headings, body text |
| `muted` | Subtitles, footers, secondary labels |

> **Note:** Built-in themes (`ocean`, `sunset`, etc.) use their own fixed palettes. Use `theme: custom` when you want to set your own colors.

## `borderRadius`

Controls the corner radius of bento cells in pixels. Default is `40`.

```markdown
---
theme: default
borderRadius: 16
---
```

Use smaller values (8–16) for a more structured, corporate look. Larger values (40–60) for a softer, modern feel.

## `fontSize`

A scale factor applied to cell body text. `1.0` is default. Use `0.85` to fit more content, `1.2` for large-text slides.

```markdown
---
theme: default
fontSize: 0.9
---
```

## Custom Fonts

Load any Google Font for headings, body text, and code:

```markdown
---
fonts:
  heading: "Playfair Display"
  body: "Source Sans Pro"
  mono: "JetBrains Mono"
---
```

Fonts are loaded from Google Fonts automatically at render time.
