# Introduction

**bentomd** is a slide deck authoring tool that turns Markdown into pixel-perfect presentations. It uses a fixed canvas renderer (1920x1080 for 16:9) with CSS transform scaling, so your content always fits the slide — no overflow, no scrollbars, no surprises.

## Design Principles

- **Fixed canvas, not responsive.** Slides render at exact pixel dimensions and scale to fit the viewport. No media queries, no viewport units.
- **Cell-first.** Every slide is a collection of bento cells (`###` headings). The layout engine places them automatically using bin-packing.
- **Content auto-detection.** You don't declare a cell type. The renderer inspects the cell's content — bold values, images, blockquotes, mermaid blocks, markdown lists — and renders accordingly.
- **Two layout families.** Full-screen slides (`cover`, `section`, `end`) and everything else (auto-bento grid).

## How It Differs

| | bentomd | Marp | Slidev | reveal.js |
|---|---|---|---|---|
| Canvas model | Fixed pixel canvas with transform scaling | CSS-based with viewport units | Vue SPA with CSS | CSS-based responsive |
| Layout system | Auto-bento grid + full-screen specials | Themes with directives | Vue layouts | Sections with CSS |
| Content types | Auto-detected in cells | Markdown only | Vue components | HTML/plugin |
| AI generation | Designed for LLM output | Possible but fragile | Possible but complex | Not practical |

## When to Use bentomd

- You want an LLM to generate slide decks with reliable, consistent output
- You need pixel-perfect slides that work on any screen size
- You want diverse content types (stats, charts, images, diagrams) in a single slide without writing HTML
- You care about visual polish without designing each slide manually
