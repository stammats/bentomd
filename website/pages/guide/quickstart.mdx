# Quick Start

## Install

```bash
npm install bentomd
```

## Create a `.bmd` File

Create `deck.bmd` with the following content:

```markdown
---
theme: default
title: My First Deck
---

## Hello, bentomd

Welcome to your first slide deck.

### :zap: Instant Slides
Write Markdown, get slides. No config needed.

### **3** Rules {sm center}
That cover everything

### :shield: Open Source {md}
MIT licensed. Runs locally, no accounts required.

### What you can do {md}
- Mix text, images, charts, and diagrams
- Apply themes and styles with one line
- Export to standalone HTML

---

## By the Numbers

### **1920px** {sm center}
Canvas width

### **99.99%** {sm center}
Overflow-free

### :layout: Auto-placed {md}
Cells are placed with bin-packing. No grid positions to manage.

### :palette: 6 Themes {md}
default · ocean · sunset · forest · berry · mono
```

## Run the Dev Server

```bash
npx bentomd dev deck.bmd
```

This opens your deck in the browser with live reload. Edit the `.bmd` file and see changes instantly.

## Build for Production

```bash
npx bentomd build deck.bmd -o output/
```

Generates a standalone HTML file you can open anywhere — no server needed.

## File Format

A `.bmd` file has two parts:

1. **Global frontmatter** — the first `---` block: theme, palette, fonts, title
2. **Slides** — each slide is a block of Markdown separated by `---`

Within each slide:

- `##` sets the slide title
- `###` defines a bento cell
- Everything inside a cell is auto-detected (text, list, image, table, blockquote, diagram)

See [Slide Structure](/guide/structure) for the full syntax reference.
